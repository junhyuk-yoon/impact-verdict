# Impact Verdict

[English](README.md) | 한국어

**무작위 실험 없이 진행한 프로모션, 기능, 가격 변경이 실제로 효과가 있었는지 판정하는 Claude 스킬입니다.**

출시 결과를 주면 비교 구간을 맞추고, 이 표본으로 판정이 가능한지부터 확인한 뒤, 정해진 다섯 가지 판정 중 하나를 근거 표와 함께 돌려줍니다. 기존 A/B 테스트 스킬은 무작위 실험을 전제로 합니다. 이 스킬은 전후 비교밖에 할 수 없는, 훨씬 흔한 경우에 씁니다.

## 1. 효과 : 4%로 보이던 비중이 9%가 되고, "성공"이 "성장 미증명"이 된다

고치기 전

```
이번 달 무료 배송 주문은 전체 주문의 4%였습니다. 영향이 작습니다.
```

고친 뒤

```
판정
- 행동 : 유효
- 이익 : 성장 미증명

| 가설 | 기준 | 실측 | 판정 |
|---|---|---|---|
| 처치 도시의 주문 증가 | 미처치 도시 대비 +10%p | +18%p (처치 +24%, 미처치 +6%) | 유효 |
| 이익 증가 | 배송비 차감 후 0 초과 | -1% (허용 범위 안) | 성장 미증명 |

집계 구간 : A 도시 3일부터, B 도시 11일부터, 모두 30일까지
가짜 시작일 검정 : 28일 전, +2%, 통과
구간 뒤 환불 : 30일 이후 환불을 되돌려 반영하면 이익 -1% → -3%

비고
- 도시별 시작일로 자르면 주문 비중은 4%가 아니라 9%
```

처음 보고서는 도시마다 다른 날 시작한 시책을 한 달 전체로 집계했습니다. 수치는 가상입니다.

## 2. 규칙 : 판정 전에 거치는 일곱 가지 확인

| 확인 | 하는 일 |
|---|---|
| 질문 분리 | "행동이 늘었는가"와 "이익이 늘었는가"를 따로 판정 |
| 구간 맞추기 | 처치군, 비교군, 분모를 모두 처치 시작일부터 집계 |
| 비교군 | 같은 세그먼트의 미처치 단위, 전년 같은 구간 차감 |
| 가짜 시작일 검정 | 가짜 시작일로 다시 계산해 ±5%를 벗어나면 판정 불가 |
| 구간 뒤 환불 | 구간이 끝난 뒤의 환불을 따로 측정해 나란히 표기 |
| 기준선 점검 | 다른 기준선으로 다시 계산해 결론이 유지되는지 확인 |
| 오염 트래픽 | 방문이 급증하고 전환율이 급락하면 오염 없는 축으로 판정 |

## 3. 판정 : 정해진 다섯 단어 중 질문마다 하나

| 판정 | 조건 |
|---|---|
| 유효 | 확인을 통과했고 비교군보다 높음 |
| 무효 | 확인을 통과했고 허용 범위를 넘는 차이 없음 |
| 판정 불가 | 가짜 시작일 검정 실패, 표본 부족, 비교군 훼손 |
| 성장 미증명 | 볼륨은 늘었으나 이익은 늘지 않음 |
| 재배분 | 처치 단위는 늘었으나 전체 합계는 그대로 |

## 4. 적용 대상 : 사후 판정용, 실험 설계는 제외

- 쓰는 곳
  - 프로모션, 쿠폰, 캠페인
  - 대조군 없이 출시한 기능과 화면 변경
  - 가격, 수수료, 정책 변경
- 쓰지 않는 곳
  - 무작위 A/B 테스트 설계
  - 표본 크기와 유의성 계산

## 5. 설치 : 명령 두 줄을 한 줄씩 입력

Claude Code에서 플러그인으로 설치합니다. 명령은 한 줄씩 따로 입력합니다. 두 줄을 한꺼번에 붙여 넣으면 한 명령으로 인식되어 실패합니다.

```
/plugin marketplace add junhyuk-yoon/impact-verdict
```

이어서 플러그인을 설치합니다.

```
/plugin install impact-verdict@impact-verdict
```

플러그인 없이 폴더만 복사해도 됩니다.

```bash
git clone https://github.com/junhyuk-yoon/impact-verdict.git
cp -r impact-verdict/skills/impact-verdict ~/.claude/skills/
```

Claude 앱(claude.ai, 데스크톱)에서는 `skills/impact-verdict` 폴더를 zip으로 압축해 설정의 스킬 메뉴에 올립니다.

## 6. 사용 예 : 상황을 평소 말로 설명하면 된다

```
지난달 세 지역에서 할인을 진행했어. 효과가 있었어?
```

```
새 결제 화면의 전후 수치야. 판정해줘.
```

```
내 분석은 +12%인데 재무팀은 +3%래. 어느 쪽이 맞아?
```

## 7. 언어 : 요청한 언어로 답한다

- 스킬 파일은 영어로 작성
- 결과물은 요청한 언어를 따름
- 예시는 모두 가상의 회사와 수치

## 8. 우선순위 : 팀이 정한 기준이 먼저다

- 스킬의 기준값과 기본 설정은 출발점이며 바꿀 수 있음
- 사용자의 명시적 지시가 스킬의 기본값보다 우선
